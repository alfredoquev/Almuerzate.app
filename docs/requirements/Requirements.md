## Requerimiento 1

- El sistema debe asignar a cada estudiante beneficiario un comedor para cada día de la semana.

## Requerimiento 2

- El sistema debe considerar el horario del estudiante al asignarle un comedor.

## Requerimiento 3

- El sistema debe considerar las preferencias del estudiante al asignarle un comedor.

## Requerimiento 4

- El sistema debe asignar al estudiante únicamente comedores que no hayan alcanzado su capacidad máxima.

## Requerimiento 5

- El sistema debe asignar al estudiante únicamente comedores que cumplan con las limitaciones registradas por el estudiante (discapacidad, restricción alimentaria).

## Requerimiento 6

- El sistema debe ejecutar la asignación de comedores de forma automática, sin intervención manual.

## Requerimiento 7

- El sistema debe permitir a los usuarios registrar reportes de inconformidades o fallas.

## Requerimiento 8

- El sistema debe notificar a los administradores cada vez que se registre un reporte o se detecte una falla.

## Requerimiento 9

- El sistema debe permitir a los administradores consultar el desempeño de los comedores (capacidad, horario y funcionamiento).
