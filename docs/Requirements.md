# Requerimiento 1

El sistema deberá permitir la asignación dinámica de un comedor para cada día de la semana, teniendo en cuenta el horario, las preferencias y la disponibilidad del usuario.

La asignación deberá realizarse de manera automática, buscando optimizar los desplazamientos hacia el comedor asignado y procurando que estos sean lo más cortos posible. De esta manera, se espera contribuir a una mayor agilidad y celeridad en la prestación del servicio.
