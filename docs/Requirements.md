# Requerimiento 1

El sistema deberá permitir la asignación dinámica de un comedor para cada día de la semana, teniendo en cuenta el horario, las preferencias y la disponibilidad del usuario.

La asignación deberá realizarse de manera automática, buscando optimizar los desplazamientos hacia el comedor asignado y procurando que estos sean lo más cortos posibles. De esta manera, se espera contribuir a una mayor agilidad y celeridad en la prestación del servicio.

# Requerimiento 2

El sistema debe contar con la capacidad de respuesta ante situaciones inesperadas (falla en la asignación de un comedor, comedores saturados, etc.). Para esto, los usuarios normales tendrán la capacidad de reportar inconformidades o fallas del sistema, las cuales serán evaluadas por un administrador. Con este fin, se le darán herramientas al administrador del programa para que pueda realizar la consulta de la información de manera más cómoda y accesible, facilitando una toma de decisiones rápida y eficiente.
